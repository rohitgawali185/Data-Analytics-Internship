# DAY 1 — Introduction to Data Analytics & Data Science

## 1. Objective

The objective of Day 1 is to understand the fundamentals of Data Analytics and Data Science, learn about different types of data, understand the data analytics lifecycle, and explore real-world applications.

## 2. What is Data?

Data refers to raw facts, figures, observations, or information collected from different sources.

Examples:
- Student marks
- Customer names
- Product prices
- Sales transactions
- Employee details

Data becomes useful when it is organized and analyzed to extract meaningful information.

## 3. What is Data Analytics?

Data Analytics is the process of collecting, cleaning, transforming, and analyzing data to identify patterns, understand performance, and support decision-making.

### Applications
- Business performance analysis
- Sales analysis
- Customer behavior analysis
- Financial reporting
- Inventory management

## 4. What is Data Science?

Data Science is an interdisciplinary field that uses statistics, programming, data analysis, and machine learning to extract insights from data and build predictive models.

### Applications
- Recommendation systems
- Fraud detection
- Demand forecasting
- Image recognition
- Predictive maintenance

## 5. Difference Between Data Analytics and Data Science

| Data Analytics | Data Science |
|---|---|
| Focuses on analyzing available data | Includes analysis and predictive model development |
| Identifies trends and patterns | Can build models to predict future outcomes |
| Commonly uses SQL, Excel, Python, and BI tools | Commonly uses Python, statistics, and machine learning |
| Supports business decisions | Supports decisions and predictive applications |

## 6. Types of Data

### Structured Data
Data organized in a predefined format, usually rows and columns.

Examples: Excel spreadsheets, SQL tables, and CSV files.

### Unstructured Data
Data that does not follow a fixed tabular structure.

Examples: Images, audio recordings, videos, and free-form text documents.

## 7. Data Analytics Lifecycle

1. Problem Definition
2. Data Collection
3. Data Cleaning
4. Data Exploration
5. Data Analysis
6. Data Visualization
7. Insight Generation
8. Decision-Making

## 8. Types of Data Analytics

### Descriptive Analytics
Explains what happened.

Example: Calculating total sales for the previous month.

### Diagnostic Analytics
Explains why something happened.

Example: Investigating why sales decreased.

### Predictive Analytics
Estimates what may happen in the future.

Example: Forecasting future product demand.

### Prescriptive Analytics
Suggests actions that may improve an outcome.

Example: Recommending inventory levels based on expected demand.

## 9. Tools Used in Data Analytics

- Microsoft Excel
- SQL
- Python

- Pandas
- Power BI
- Tableau
- Matplotlib

## 10. Conclusion

Data Analytics helps transform raw data into meaningful insights. Understanding data, following a structured analytical process, and using appropriate tools are essential foundations for a career in Data Analytics.
