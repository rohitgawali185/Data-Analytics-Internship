# DAY 12 — Excel and Power BI Fundamentals

## Objective
To learn spreadsheet analysis and interactive dashboard development using Excel and Power BI.

## Tools Used
- Microsoft Excel
- Microsoft Power BI Desktop

## Tasks Performed

### 1. Excel Fundamentals
- Practiced sorting and filtering.
- Used basic Excel formulas.
- Learned PivotTables.

### 2. Power BI Data Import
- Imported the dataset into Power BI Desktop.
- Explored the dataset using Data View.

### 3. Power Query
- Practiced basic data transformation.
- Checked column names and data types.

### 4. DAX Measures
- Created basic DAX measures.
- Calculated Total Sales.
- Calculated Total Profit.
- Calculated Profit Margin.

### 5. Data Visualization
- Created KPI Cards.
- Created Column Charts.
- Practiced interactive dashboard elements.

## Key Learnings
- Understanding Excel data analysis.
- Importing and transforming data in Power BI.
- Creating basic DAX measures.
- Developing visual reports.

## Conclusion
Successfully completed the fundamentals of Excel and Power BI. Learned how to transform data, calculate business metrics, and present information through visual reports.
