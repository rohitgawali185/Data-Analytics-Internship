## About This Repository

Welcome to my **Data Analytics Internship** repository.

This repository documents my 15-day learning journey in Data Analytics, including practical exercises, assignments, Python programming, SQL queries, data manipulation, visualization, statistical concepts, and introductory Machine Learning.

The main objective of this internship work is to develop practical data analytics skills and understand how raw data can be transformed into meaningful insights that support business decision-making.

I have used Python, Jupyter Notebook, SQL, Excel, Power BI, and GitHub to complete and organize my learning activities.

## How to Explore This Repository

1. Clone the repository:

```bash
git clone https://github.com/rohitgawali185/Data-Analytics-Internship.git
```

2. Open the project folder in Visual Studio Code.

3. Install the required Python libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

4. Open the required `.ipynb` notebook using Jupyter Notebook.

5. Explore the SQL files and execute queries using MySQL or SQLite, depending on the file.
